Best First Step

If you are brand new, use this order:

  1. Open the First 10 Minutes guide.
  2. Use the Mode Guide to learn the difference between Chat, Cowork, and Code.
  3. If something goes wrong, open Common Issues.

Important Before You Use Code

  • Claude Code can read the files in the folder you opened.
  • It cannot guess the right project if the wrong folder is open.
  • Most beginners do not need a skill or integration to start asking questions.
  • If you are unsure, ask Claude what folder and files it can currently see.
