Quick start

If you want the easiest path, copy this command into Terminal:

bash <(curl -fsSL https://raw.githubusercontent.com/Jcali86/claude-helper/main/setup.sh)

It downloads the repo, opens the starter pages, and gives you a solid place to begin without a bunch of setup chaos.

What this project helps with

  • understanding Claude Chat, Cowork, and Code
  • learning Mac and Terminal basics in plain language
  • using AI for positive daily life, learning, and creativity
  • building small projects without needing to become "the tech person"
