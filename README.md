# Claude Helper

Claude Helper is a beginner-friendly guide for people who are new to Claude, new to Mac workflows, or just tired of instructions that assume too much too early.

If you are here to learn Claude, do not start on GitHub.

Start here instead:

- website: [https://jcali86.github.io/claude-helper/](https://jcali86.github.io/claude-helper/)
- get Claude first: [https://jcali86.github.io/claude-helper/docs/get-claude.html](https://jcali86.github.io/claude-helper/docs/get-claude.html)
- mode guide: [https://jcali86.github.io/claude-helper/docs/chat-code-cowork.html](https://jcali86.github.io/claude-helper/docs/chat-code-cowork.html)
- common issues: [https://jcali86.github.io/claude-helper/docs/common-issues.html](https://jcali86.github.io/claude-helper/docs/common-issues.html)

The live site is the beginner experience.

This GitHub repo is the source behind that site.

## Beginner Rule

Most people do not need GitHub, Terminal, Claude Code, skills, connectors, or plugins to get started.

The best first win is:

1. Open Claude
2. Stay in Chat
3. Send one simple message
4. Learn the other tabs later
