# Claude Helper

Claude Helper is a beginner-friendly starter repo for people who are new to AI, LLMs, Mac apps, and Terminal.

The goal is to help someone go from "I mostly use my phone or browser" to "I can use Claude Chat, Cowork, and Code with confidence."

## What "Effective" Means Here

In this repo, "effective" means:

- using simple words instead of technical jargon
- understanding what each Claude option is good at
- knowing what to click, paste, or install next
- fixing common setup problems without panic
- using AI for positive, practical, everyday help

## Start Here

1. Open the `Terminal` app on your Mac.
2. Copy and paste the command below.
3. Press `Return`.

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Jcali86/claude-helper/main/setup.sh)
```

What the setup script does:

- downloads or updates this repo into `~/Documents/Claude-Helper`
- opens a simple FAQ page in your browser
- opens the project folder in Finder
- points you to the best "start here" files

## Which Claude Option Should I Use?

`Chat`

Use this when you want to talk through an idea, ask questions, get help learning something, or create content together.

`Cowork`

Use this when you want more guided, collaborative help on a bigger task that may take several steps and some back-and-forth.

`Code`

Use this when you want Claude to help you inside a project folder, work with files, explain Terminal commands, or build and fix things step by step.

More detail: [docs/chat-code-cowork.md](docs/chat-code-cowork.md)

## Positive Ways To Use AI

This repo focuses on helpful, grounded use cases such as:

- creativity prompts and family game ideas
- school support and study planning
- writing help without sounding robotic
- organizing projects and daily life
- helping older adults understand scam risks and privacy basics
- finding trustworthy help, local services, food banks, or news sources
- building small automations that save time
