Step 2

Three tabs. One easy rule.

You do not need to memorize everything. Just remember this: start with Chat. The other two can wait until you actually need them.

Next: First 10 Minutes Back to Get Claude
Start here

Chat

Use Chat when you want to ask, learn, plan, write, or talk through an idea in normal language. This is the safest place to start if you are still building confidence.

  • Ask questions
  • Learn a new topic
  • Write or rewrite something
  • Brainstorm ideas
  • Plan something before you build it

Starter prompt:

I am new to this. Please explain what you can help me with in simple language, then give me three good first things to try.

Optional later

Cowork is for bigger tasks

Use Cowork when the task has many parts and you want a guided partner to help you move through it.

Cowork may require a paid Claude plan. You do not need it for your first success.

  • Break a project into steps
  • Compare options before spending time or money
  • Organize a task that feels like a lot
  • Work through something over time

Starter prompt:

Help me turn this into a simple plan. I want small steps, plain English, and a clear next action. If there is anything I do not need yet, tell me that too.

See real Cowork screenshots

Only for bigger projects

Code is for files and projects

Use Code when Claude is helping inside a real folder on your Mac. This is the mode for files, commands, setup, and building projects.

You do not need Code on day one. Come here when you are ready to work with files or build something real.

  • Build or improve a project
  • Edit files safely
  • Explain Terminal commands
  • Fix errors
  • Set up tools step by step

Starter prompt:

Before we change anything, please tell me what folder and files you can currently see. I am new to Terminal and want each step explained in plain English.

See real Code screenshots

Quick way to choose

  • Pick Chat when you want conversation, explanation, or planning.
  • Pick Cowork later when the task is bigger and you want more structure.
  • Pick Code later when the task involves files, folders, Terminal, or a real project.

Important before you use Code

Claude Code can read the files in the folder you opened. It cannot guess the right project if the wrong folder is open. Open the project folder first, then paste your prompt.

Do you need skills or integrations?

Usually, no. Most beginners do not need a skill or integration to ask questions or start a simple project. Start simple first. Add extra tools only when you know why you need them.
