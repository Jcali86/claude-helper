How to use this page

  1. Read the short explanation.
  2. Look at the example screen.
  3. Copy the sample prompt and change it to fit your life.
  4. Notice that good prompts are usually simple, clear, and honest.
Minute 1 To 3

Start with Chat

Chat is usually the best first step because it feels closest to a normal conversation.

Try this prompt:

Hi Claude. Help me learn what I can actually do with you. I am new to AI and want to learn the basics, but please keep it simple, practical, and not overly technical.

Why this works: it tells Claude your level, your preference, and your goal without making the prompt too complicated.

Minute 4 To 6

Use Cowork for bigger tasks

Cowork is helpful when you want a more guided partner for a task with more moving parts.

Try this prompt:

Help me make a realistic plan to learn Claude without getting overwhelmed. I want small steps, plain English, and examples that fit real life, not generic productivity advice.

Good uses include project planning, learning paths, and real-life tasks that need structure and follow-through.

Minute 7 To 10

Use Code when files or Terminal are involved

Code is where Claude helps inside a real folder. This is useful for building tools, fixing setup issues, and explaining Terminal commands.

Important: open the project folder first. Claude Code can read the files in the folder you opened, but it cannot guess the right project if the wrong folder is open.

Most beginners do not need a skill or integration to ask questions or start a simple project.

If you are unsure, say this first:

Before we start, please tell me what folder and files you can currently see.

Try this prompt:

You are looking at my current project folder. I am new to Terminal and coding projects, so please explain every step in plain English before we do it. Help me build a very simple app that pulls in positive local news and shows me a clean summary.

The key is telling Claude to slow down, explain things as it works, and not assume you already know advanced steps.

Three prompts worth keeping

Beginner mode

Please explain this as if I am smart but new to this. Use simple language and show me one step at a time. Do not skip the obvious bits.

Show me what good looks like

Show me a solid example prompt, the kind of answer I should expect, and why that prompt works.

Help me stay calm

If something could break or confuse me, tell me before we do it. Flag the risky part first, then show me the safe next step.
