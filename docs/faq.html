What is Claude Chat?

Chat is the easiest place to start. You ask questions, explain what you want, and Claude helps you think, write, learn, or plan.

What is Cowork?

Cowork is a more guided way to work through a larger task with AI as a partner. It is useful when the job has many steps and you want help staying organized.

Learn more

What is Claude Code?

Claude Code helps inside a real folder on your computer. It can explain files, help with Terminal commands, and build or fix projects.

Important beginner tip: Claude Code can read the files in the folder you opened. It cannot guess the right project if the wrong folder is open.

Learn more

What is Terminal?

Terminal is a text window where you can tell your Mac to do things by typing commands instead of clicking buttons.

What is a skill?

A skill is a reusable set of instructions or workflows that helps Claude do a certain kind of job more consistently.

Most beginners do not need a skill or integration to ask questions or start a simple project.

See examples

What is an integration?

An integration connects Claude to another tool or service so it can work with outside information in a more useful way.

For simple beginner use, you usually do not need to set one up right away.

What is a container?

A container is a simple way to package an app so it runs the same way on different computers without lots of manual setup.

What is a folder path?

A folder path is the address of a folder on your Mac. If paths feel confusing, drag a folder from Finder into Terminal and your Mac will paste the path for you.

Good first uses for AI

  • Learn a topic in simple language.
  • Write a message, email, or plan.
  • Make a checklist for something stressful.
  • Get help understanding scams or suspicious messages.
  • Turn an idea into a simple project.
  • Build a small app or automation one step at a time.
