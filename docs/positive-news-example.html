Example App

Positive local news digest

This is the first real project in the repo. It is small enough for a beginner to understand, useful enough to feel real, and simple enough to improve with Claude step by step.

Back to homepage Code examples Common Issues

What this app does

  • Reads a small list of local or community feeds
  • Looks for positive or community-helpful stories
  • Builds a short digest page in the browser
  • Can run on your Mac with Python
  • Can later be packaged with Docker

Why this is a good first project

  • It does something useful in real life.
  • It shows how data, filtering, and a simple web page fit together.
  • It is small enough for Claude Code to explain clearly.
  • It gives you a safe base for trying improvements in phases.

How to run it locally

From inside the positive-news-digest folder, run:

python3 app.py

Then open:

http://localhost:8000

Before you ask Claude Code for help

Open the positive-news-digest folder first.

Claude Code can read the files in the folder you opened. It cannot guess the right project if the wrong folder is open.

Most beginners do not need a skill or integration to start working on this project.

If you want to check the folder first, paste this:
