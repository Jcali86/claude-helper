# Chat, Cowork, and Code

This file explains the three options in simple language.

## Chat

Think of `Chat` like sitting down with a helpful assistant and talking things through.

Use it for:

- asking questions
- learning new topics
- writing and rewriting
- brainstorming ideas
- planning trips, meals, projects, or events
- making something easier to understand

Examples:

- "Explain what Terminal is like I am new to Mac."
- "Help me write a polite email."
- "Give me 10 family game night ideas."

## Cowork

Think of `Cowork` like having a partner help you work through a bigger task with more structure and back-and-forth.

Use it for:

- multi-step planning
- breaking down a project into smaller actions
- doing deeper research before acting
- keeping momentum on something that feels overwhelming
- organizing a real-world task that has many moving parts

Examples:

- planning a side project
- mapping out a learning path for AI
- organizing a move, trip, or family event
- comparing choices before spending money or time

## Code

Think of `Code` like bringing Claude into a real folder on your computer so it can help with files, commands, and projects.

Before you use `Code`, open the project folder you want help with.

That is what gives Claude the context for the files, folders, and app you are talking about.

You do not need a special Skill or integration for normal beginner steps.

Use it for:

- building apps
- editing files
- fixing errors
- understanding Terminal commands
- setting up development tools
- making scripts and automations

Examples:

- "Build a simple local news digest app."
- "Why did this install fail?"
- "Explain this error in plain English."
- "Create a starter website for my project."

Good first line if you are unsure:

- "Before we start, tell me what folder and files you can currently see."

## Which One Should I Pick?

Pick `Chat` when you want conversation.

Pick `Cowork` when you want help managing a larger task.

Pick `Code` when you want help inside a folder, app, repo, or Terminal workflow.

## Real-Life Positive Uses

- helping a student study without shame
- planning healthier routines
- turning a family idea into a printable activity
- writing questions before speaking to a school, bank, or doctor
- explaining scams and suspicious messages in plain language
- creating useful tools for your local community
