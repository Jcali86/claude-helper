Mac Basics

Where are my files? A quick guide.

A folder path is just the address of a file or folder on your Mac. The good news: you almost never need to type one by hand.

Back to homepage Common Issues FAQ

What a path looks like

Example:

/Users/yourname/Documents/Claude-Helper

That means: start at your user account, open Documents, then open the Claude-Helper folder.

The easiest beginner method

  1. Open Finder.
  2. Find the folder you want.
  3. Drag that folder into the Terminal window.

Your Mac will paste the full path for you.

What ~ means

The ~ symbol means your Home folder.

~/Documents

It points to the same general place as /Users/yourname/Documents.

How paths go wrong

  • You copied someone else's username.
  • You copied a folder name that does not match your Mac.
  • You guessed instead of dragging the folder in.

Plain-English example

If someone gives you this path:

/Users/jamie/Documents/Project

and your Mac username is Chris, your version would need to use:

/Users/Chris/Documents/Project

Best habit to keep

If you are unsure, do not guess. Use Finder, then drag the folder into Terminal.
