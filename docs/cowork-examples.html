What this page shows

These screenshots are good for explaining what Cowork looks like before and after a task is written, plus what the add menu exposes for files, skills, connectors, and plugins.

Text annotations

  • What this screen is: Cowork is for bigger tasks that need more structure than a normal chat.
  • What you type or click here: Describe the task in the main box, then use the main action button when it looks right.
  • What beginners can ignore for now: Skills, connectors, and plugins are optional extras, not day-one requirements.
  • Most important tip: Use Cowork when the job has several steps and you want help staying organized.
