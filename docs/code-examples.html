What this page shows

These screenshots are useful for explaining the beginner-important part of Claude Code: open the project first, then ask for help.

Text annotations

  • What this screen is: Claude Code working inside a real project folder on your Mac.
  • What you type or click here: Open the right folder first, then type your prompt in the main box.
  • What beginners can ignore for now: Branch, worktree, connectors, and plugin options can usually wait.
  • Most important tip: Claude can only see the files in the folder you opened.
