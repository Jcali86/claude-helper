Windows Basics

Where are my files? A quick guide.

A folder path is just the address of a file or folder on your PC. The good news: you almost never need to type one by hand.

Back to homepage Common Issues

What a path looks like

Example:

C:\Users\yourname\Documents\Claude-Helper

That means: start at the C: drive, open your user account, open Documents, then open the Claude-Helper folder. Windows uses backslashes (\) between folders.

The easiest beginner method

  1. Open File Explorer.
  2. Find the folder you want.
  3. Drag that folder into the Command Prompt or PowerShell window.

Windows will paste the full path for you.

What %USERPROFILE% means

On Windows, %USERPROFILE% means your Home folder.

%USERPROFILE%\Documents

It points to the same place as C:\Users\yourname\Documents.

You might also see ~ used in PowerShell — it works the same way there.

How paths go wrong

  • You copied someone else's username.
  • You copied a folder name that does not match your PC.
  • You used the wrong drive letter (like D: instead of C:).
  • You guessed instead of dragging the folder in.

Plain-English example

If someone gives you this path:

C:\Users\jamie\Documents\Project

and your Windows username is Chris, your version would need to use:

C:\Users\Chris\Documents\Project

Another way to get the path

In File Explorer, click the address bar at the top. It will show you the full path, and you can copy it directly.

This works great if dragging feels awkward.

Best habit to keep

If you are unsure, do not guess. Use File Explorer, then drag the folder into Command Prompt or PowerShell — or click the address bar and copy.
