Step 1

Get Claude without the confusing bits.

This page is for the very start. If this feels new, that is normal. You do not need GitHub, Command Prompt, or Claude Code for this step.

Get Claude Desktop Use Claude in your browser

Do this in order

  1. Pick whichever feels easier right now.
    Desktop is a Claude app you install on your PC. Browser means you just open a website — nothing to install.
  2. Open Claude.
    If you picked Desktop, follow the official Claude Desktop page and open the app after it installs. If you picked browser, open claude.ai.
  3. Sign in or create your Claude account.
  4. Stay in Chat.
    You do not need Cowork or Code yet.
  5. Copy this first message and send it:
    Hi Claude. I am new to this. Please help me get comfortable using Claude on my Windows PC. Keep it simple, practical, and one step at a time.

What success looks like

You are signed in, you can see Chat, and Claude replies to your first message. That is it. Everything else can wait.

If this already feels confusing

Use Claude in your browser first. That means opening a website in Chrome or Edge instead of installing anything on your PC right away.

Once that feels easy, come back and try Claude Desktop later.

Windows words in plain English

  • Browser: the app you use to open websites, like Chrome or Edge.
  • App: a program on your PC.
  • File Explorer: the Windows app used to look at files and folders.
  • Taskbar: the row of app icons usually at the bottom of your screen.
  • Search (Windows key): press the Windows key to search for apps and files on your PC.
  • Command Prompt / PowerShell: a text window for commands. You do not need it for this step.

If you get stuck

If Claude does not open, if sign-in feels confusing, or if you are not sure what you are looking at, use the help page next.
