Something not working? Start here.

If something does not work the first time, that does not mean you broke anything. Find the problem that sounds like yours, try one fix, and move on.

Chat and beginner issues

Claude is not answering the way I expected

That happens. Try rephrasing your message with more detail about what you actually want.

A good formula:

I want [specific result]. I am [your experience level]. Please keep it [simple / step by step / short].

The more Claude knows about what you need, the better the answer gets.

I do not know which tab to use

Start with Chat. It is the simplest and works for most beginner tasks. Cowork and Code are for later, when you have a bigger task or a real project folder.

Open the mode guide

I do not know where my files are

That is normal if you mostly use your phone, browser, or apps that hide the file system. Finder plus drag-and-drop is the easiest way to get the right folder path into Terminal.

Project and Terminal issues

Claude seems confused about the project

This usually means Claude Code is not looking at the right folder yet. Claude Code can read the files in the folder you opened. It cannot guess the right project if the wrong folder is open.

Try this prompt first:

Before we start, please tell me what folder and files you can currently see.

"Operation not permitted"

This usually means macOS is blocking access until you approve it.

  • Look for a permission popup behind another window.
  • Open System Settings, then Privacy & Security.
  • Allow access if Terminal or your coding app is listed.
  • Run the command again.

"git: command not found"

Git is one of the basic tools many coding projects use. You only need this if a project asks for it.

Try this command in Terminal:

xcode-select --install

When the install finishes, close Terminal, open it again, and try the command one more time.

"No such file or directory"

This usually means the folder path is wrong. Open the folder guide — it shows the easiest beginner method for getting the right path.

Open Folder Paths

A pasted command looks weird

Sometimes smart quotes or hidden formatting break a Terminal command.

  • Copy the command again from the guide.
  • Make sure the quotes are normal, like "this".
  • Paste into Terminal directly, not into Notes first.

Good safety habits

  • Ask Claude to explain a command before you run it.
  • Keep copies of important files before big changes.
  • Do not share passwords or sensitive personal information.
  • Slow down when something feels unclear instead of guessing.
